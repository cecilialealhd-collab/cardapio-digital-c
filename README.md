# 🍽️ Cardápio Digital em C

Projeto desenvolvido durante meus estudos de Análise e Desenvolvimento de Sistemas (ADS), com o objetivo de praticar lógica de programação utilizando a linguagem C.

## 📌 Sobre o projeto

O Cardápio Digital simula o sistema de pedidos de um restaurante, permitindo que o usuário escolha produtos de diferentes categorias, acompanhe o subtotal e visualize o valor final da conta.

## ⚙️ Funcionalidades

- Exibição de pratos principais, bebidas e sobremesas.
- Seleção de vários produtos no mesmo pedido.
- Atualização do subtotal após cada escolha.
- Desconto de 10% para pedidos a partir de R$ 100,00.
- Validação de entradas inválidas.
- Aviso quando uma opção não existe no cardápio.
- Cálculo do desconto e do total a pagar.
- Exibição do resumo final do pedido.

## 🛠️ Tecnologias utilizadas

- Linguagem C
- GCC (compilador)
- Visual Studio Code

## ▶️ Como executar

Para executar o programa, é necessário ter um compilador C, como o GCC, instalado no computador.

1. Abra o terminal na pasta onde está o arquivo `main.c`.
2. Compile o programa utilizando o comando:

```bash
gcc main.c -o cardapio
```

3. Execute o programa no Windows:

```bash
.\cardapio.exe
```
